# ESP32 Hardware Design

This folder contains the conceptual hardware schematic for the Office Electricity Monitor, designed using Wokwi.
It simulates the ESP32 microcontroller setup used to monitor and actuate the connected relays for lights and fans.

## Files
- `diagram.json`: The visual wiring and component layout.
- `sketch.ino`: The Arduino/ESP32 C++ firmware code for reading states and communicating with the backend API.
